Thank you for downloading my mod! Here are some instructions to start it up

1. This mod was made using yamagi Quake 2, as the steam version of quake 2 runs the enhanced version, and will not be able to run this mod.
Link to download:https://www.yamagi.org/quake2/

2.  After donloading both the mod and Yamagi, you're gonna want to place the mod in baseq2 if it isn't already in there.
(for some reason my mod wont work if its in a separate folder, it needs to be in baseq2)

3. Afterwards, you can simply make a shortcut of yQuake-2 and start playing.

4. This mod is only usable in Single Player mode, so do not choose multiplayer when playing this mod.

When you first spawn in, you will notice some items in your starting inventory:

* Blaster( default weapon, simply ignore this)
* 1 Grenade (Do not throw this, as this serves as an imaginary ammo for the Capture Ball item)
* Capture Ball (Icon looks like the grenade launcher, select it using "]" and hitting "ENTER" on the icon)

(NOTE: If you threw the grenade, the capture ball wont be able to be equipped as it will no longer
have any ammo and thus will no be accessible unless you get another grenade. In case of emergencies,
simply open the console using the "`" key and enter "give grenades" to fix the problem.)

Once you have equipped the Capture Ball, you can now play with the mod:

*Throw capture Balls using the attack action ("Left CTRL" key or "MOUSE LEFT"),
 and whenever it hits a monster, they will immediately be captured.

*Once a monster is captured, summon them using the "g" key

Once summoned, the monster will be able to use 4 skills(WIP)
* To activate skill 1, use the "y" key
* To activate skill 2, use the "u" key
* To activate skill 3, use the "h" key
* To activate skill 4, use the "j" key

*To put the monster away, simply throw another capture ball at it.


With that, I hope you enjoy the mod, and have fun Capturing.
